Why MaliciousSkillBench?

Existing malicious Agent Skill resources are fragmented across sources, artifact formats, provenance conventions, label evidence, and benign support. MaliciousSkillBench consolidates these resources rather than concatenating them, with canonicalization, deduplication, structural control, cross-label conflict handling, and benchmark-specific evaluation protocols.

Detection Findings

Word-SVM Macro-F1 remains high under random and structural-disjoint splits, then drops under source shift. This is source-conditioned generalization, not a universal out-of-distribution claim.

0.932 Random Macro-F1
0.916 M-Structural-Disjoint
0.665 Source-Disjoint

Under Source-Disjoint evaluation, Word-SVM retains 95.6% malicious recall but reaches a 62.4% benign false-positive rate. Cross-source degradation is dominated by benign over-flagging while malicious recall remains high.

Dataset Access

Static Benchmark — Hugging Face hosts the directly loadable static benchmark and metadata for all 9,740 identities. Exact frozen text is available for 9,735; five sensitive records provide sanitized public representations.

Dataset: https://huggingface.co/datasets/ProtectSkills/MaliciousSkillBench

from datasets import load_dataset

dataset = load_dataset("ProtectSkills/MaliciousSkillBench")

Full Skill Packages — reviewed source-package archives are distributed separately through GitHub Releases when redistribution is authorized. The current full-package release is SRC002 only: 157 accepted source artifacts (152 preserved snapshot packages and 5 sanitized packages). Other source packages are not publicly downloadable yet.

Full Packages: https://github.com/protectskills/MaliciousSkillBench/releases/tag/src002-full-packages

Getting Started

The GitHub repository hosts code, documentation, reproducibility artifacts, and reviewed full-package releases. The Dataset button points to the Hugging Face static benchmark. The Full Packages button points to the SRC002 GitHub Release. The Paper button points to the public preprint.

Responsible Use

The benchmark includes static public representations, and reviewed full package artifacts are additionally available for SRC002. Do not execute untrusted Skills or untrusted packages. See RESPONSIBLE_USE.md.
