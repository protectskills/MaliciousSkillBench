GitHub Pages source for MaliciousSkillBench.

Serve this `docs/` directory as the project site. Publication URLs are centralized in `assets/js/config.js`:

- `PAPER_URL` — empty until a public paper URL is assigned
- `DATASET_URL` — https://huggingface.co/datasets/ProtectSkills/MaliciousSkillBench
- `GITHUB_URL` — https://github.com/protectskills/MaliciousSkillBench
- `DOCS_URL` — https://github.com/protectskills/MaliciousSkillBench/tree/main/benchmark

Empty paper values are placeholders, not live links. Relative documentation files live in the parent GitHub repository, not in this site root. GitHub Pages is not enabled by this source tree alone.
