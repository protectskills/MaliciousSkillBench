GitHub Pages source for MaliciousSkillBench.

Serve this `docs/` directory as the project site. Publication URLs are centralized in `assets/js/config.js`:

- `PAPER_URL` — empty until a public paper URL is assigned
- `DATASET_URL` — empty until a Hugging Face dataset URL is assigned
- `GITHUB_URL` — https://github.com/protectskills/MaliciousSkillBench
- `DOCS_URL` — empty; in-page documentation anchors are used until a dedicated docs URL exists

Empty paper/dataset values are placeholders, not live links. Relative documentation files live in the parent GitHub repository, not in this site root.
